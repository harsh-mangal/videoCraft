# Videocrafts India Website

Responsive React website for Videocrafts India, a photography and videography studio in Chandigarh.

## Enquiry flow

The project intentionally has no backend. Contact forms validate in the browser and open WhatsApp to **+91 98886 26212** with the visitor's enquiry details prefilled. The visitor reviews and sends the message from WhatsApp.

## Run locally

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

Upload the contents of `build/` to the hosting public directory. The included `public/.htaccess` supports React Router on Apache/Hostinger, while `public/_redirects` supports platforms such as Netlify.
